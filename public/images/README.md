# Photo guide

Drop your own photos in this folder using these exact names (.jpg, .webp or .png). Until a file exists, a sample photo is shown.
Recommended sizes are width x height in pixels (larger is fine, keep the same shape).

| File name | Size | What to shoot |
|---|---|---|
| `hero.jpg` (or `hero-leopard.jpg`) | 900x1200 | Tall/portrait hero: a leopard resting on a branch or rock, golden light |
| `stay-main.jpg` | 1000x1250 | Warm exterior or veranda of your accommodation, ideally at sunrise |
| `room-1.jpg` | 900x700 | Your standard room, bed made, natural light |
| `room-2.jpg` | 900x700 | Your family room |
| `room-3.jpg` | 900x700 | Group / shared stay option, or dining & lounge area |
| `sighting-leopard.jpg` | 700x900 | Sri Lankan leopard |
| `sighting-bear.jpg` | 700x900 | Sloth bear |
| `sighting-elephant.jpg` | 700x900 | Elephant near a villu |
| `sighting-birds.jpg` | 700x900 | Painted storks, peacock or another Wilpattu bird |
| `sighting-deer.jpg` | 700x900 | Spotted deer |
| `gallery-01.jpg`, `gallery-02.jpg`, ... | any | Gallery photos. Add as many as you like; they appear in filename order. |
| `hero-lake.jpg` | 2400x1350 | OPTIONAL wide lake/shoreline photo (kept in colour). Only the WATER area ripples. The water line is set in `photoWaterTop()` in `src/components/WaterCanvas.tsx` - adjust it if you change the photo. Keep it under ~600 KB. If absent, a built-in illustrated black & white lake is used. |
